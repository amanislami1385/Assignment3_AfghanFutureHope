## Project Overview

This project was created for Assignment 3 of WEB Technologies 1.

The main purpose of this assignment was to practice responsive web design using both custom CSS and Bootstrap 5.3.

For the project, I created a responsive website for **Afghan Future Hope**, an organization focused on education, digital skills, scholarships, and opportunities for Afghan youth.

The website was designed to work on mobile phones, tablets, and desktop computers.

---

## Assignment Requirements

### Task 1 – Custom CSS

For the first task, I created a Programs section using my own CSS.

The section uses CSS Grid and changes according to the screen size:

- 1 column on small screens
- 2 columns on tablets
- 4 columns on larger screens

I also used media queries to change font sizes, spacing, and other elements for different screen sizes.

No Bootstrap grid classes were used for this section.

### Task 2 – Bootstrap

For the second task, I used Bootstrap 5.3 for the rest of the website.

The project includes:

- Bootstrap container
- Bootstrap rows and columns
- Responsive breakpoints
- Responsive navbar
- Bootstrap buttons
- Bootstrap cards
- Bootstrap accordion
- Bootstrap utility classes
- `order-*` classes
- Responsive form
- Mobile-only content

The opportunity cards display one card per row on mobile, two on tablets, and three or more on larger screens.

---

## Responsive Design

The website was tested for different screen sizes:

- **375px** – Mobile
- **768px** – Tablet
- **1280px** – Desktop

The layout changes automatically depending on the screen width.

Images are also responsive so that they fit different screen sizes without creating horizontal scrolling.

## Design

I used a dark navy and gold color theme.

Navy gives the website a professional and serious appearance, while gold is used to highlight important information and buttons.

I also added student and education-related photographs to make the website more realistic and connected to its purpose.
